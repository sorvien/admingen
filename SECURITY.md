# Security Policy

## Supported Versions

We actively support and release security fixes for the latest version of AdminGen.

| Version | Supported          |
| ------- | ------------------ |
| 0.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within AdminGen, please do **NOT** open a public issue.

Instead, please send an email to security at [support@sorvien.com](mailto:support@sorvien.com) or use [GitHub Private Vulnerability Reporting](https://github.com/sorvien/admingen/security/advisories/new).

Please include:
- A description of the vulnerability and its potential impact.
- Clear steps or a minimal proof of concept to reproduce the issue.
- Any relevant logs, code samples, or screenshots.

We take security seriously and will acknowledge your report within 48 hours and work with you on a timely resolution.
